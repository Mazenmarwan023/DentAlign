# Screenshots Folder Checklist

Save your website screenshot image files in this directory (`docs/screenshots/`) using these exact filenames:

1. `01-home-page.png` - Homepage & Landing Portal
2. `02-login-page.png` - Login & Role Authentication
3. `03-staff-dashboard.png` - Doctor & Staff Dashboard
4. `04-cdss-segmentation.png` - AI Caries Detection (CDSS)
5. `05-radiology-suite.png` - Radiology & SimpleITK Filters
6. `06-analytics-reports.png` - Practice Analytics & Financial Reports
7. `07-dicom-viewer.png` - Interactive DICOM Viewer
8. `08-patient-portal.png` - Patient Portal & Booking Flow

Once added, commit and push to GitHub:
```bash
git add docs/screenshots/
git commit -m "Add website screenshots"
git push
```
